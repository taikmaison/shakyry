# Свои шаблоны (`services/catalog/own/`)

Шаблоны, которые мы рисуем сами: казахские орнаменты в SVG из кода, свободные шрифты (SIL OFL), без фото
и без чужих картинок. Права наши — всё лежит в git. **Ничего не копировать с других сайтов** (в т. ч. из
скачанных чужих шаблонов): ни картинки, ни разметку, ни узоры по точкам — рисуем свои.

```
own/
  build.js            сборка: node own/build.js [префикс файла описаний]   (из папки services/catalog)
  lib/ornaments.js    библиотека орнаментов (рог «қошқар мүйіз», ромбы, тұмар, волна, розетки, арка, уголки)
  lib/layouts.js      раскладки страницы (5 видов шапки + общая часть)
  specs/*.js          описания шаблонов — каждый файл: module.exports = [ {…}, {…} ]
  templates/<id>.json media/<slug>-*.svg catalog.json fonts.css previews/  — результат (в git)
  fonts/              OwnCormorant(.woff, обычный и курсив), OwnMontserrat — с казахскими буквами и ₸
```

Каталог сайта показывает свои шаблоны в конце; картинки — `/media/own/<файл>`, шрифты — `/fonts/own/<файл>`.

## Описание шаблона (spec)

```js
{
  id: 9005, slug: 'tusau2', category: 'tusaukeser',      // id и slug — уникальные; category — ключ вида тоя
  layout: 'arch',               // classic | arch | darkhero | bordered | medallion
  palette: {
    bg, card, line,             // фон страницы, фон рамок, цвет рамок
    ink, name, accent, soft,    // основной текст, имя, акцент (золото и т. п.), мягкий фон для рисунков
    button, buttonText,         // кнопки (анкета, карта, музыка) — контраст ≥ 4.5:1
    dark, light,                // только для darkhero: фон шапки и текст на нём
  },
  envelope: ['#цвет конверта', '#цвет текста на конверте'],
  style: { band: 'horn|diamond|wave|tumar', divider: 'horn|diamond|wave|tumar', rosette: 'horn8|star8|flower', heading: 'serif|caps' },
  motif: (P, O) => O.svg(w, h, '…'),   // главный рисунок (SVG-строка); P — палитра, O — lib/ornaments.js
  motifW: 260, motifH: 200,            // размер рисунка на странице (px, ширина страницы 390–430)
  // необязательно (по умолчанию — для праздника):
  greeting: 'Құрметті ағайын-туыс, дос-жаран!', dateTitle: 'Той салтанаты', hostsTitle: 'Той иелері',
  timer: 'Тойға дейін қалды:',         // null — без обратного отсчёта
  rsvpTitle: 'Тойға келетініңізді растаңыз', rsvp: ['Иә, барамын!', 'Жұбайыммен бірге барамын', 'Өкінішке орай, келе алмаймын'],
  wishes: true, wishesTitle: 'Ізгі тілектер', footer: 'Сіздерді асыға күтеміз!',
  music: '/media/cd/0ad6707e677a88.mp3', // null — без музыки
  calm: false,                           // true — розетка внизу не вращается (ас беру)
  marker: 'heart',                       // отметка дня в календаре: heart | circle
}
```

Метки, которые подставляет сайт: `TITLE`, `ИМЯ` (имя виновника), `DATE`, `CITY`, `ADDRESS`, `HOST`, `INVITE_TEXT`
(раскладка ставит их сама). Свои надписи в описании — на казахском, проверенные.

## Проверка

```bash
node own/build.js tusaukeser                           # собрать свои описания
curl -s -X POST http://127.0.0.1:8331/_internal/reload  # каталог перечитывает шаблоны (тестовый сайт на 8324)
node tools/own-render.js <папка> 9005 9006             # полный снимок страницы с примером данных + шапка крупно
```

Смотреть снимки обязательно: рисунок узнаётся, ничего не налезает, текст читается, цвета гармоничны.
