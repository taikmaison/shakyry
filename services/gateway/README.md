# gateway — шлюз

Единая точка входа. Раздаёт запросы сервисам по `routes.json` и передаёт ответ потоком.
Служебные адреса (`/_internal/…`, `/events`) снаружи закрыты; пути с `//`, `..`, `\`, `%2f` отклоняются. Своих данных нет.

## Окружение
`PORT`, `HOST`, `AUTH_URL`, `CATALOG_URL`, `INVITATIONS_URL`, `GUESTS_URL`, `ALBUM_URL`, `WEB_URL`.
`TRUST_PROXY=1` — только если перед шлюзом стоит свой nginx или балансировщик: тогда IP клиента берётся из его `X-Real-IP` / `X-Forwarded-For` (для лимитов). Без него заголовок от клиента игнорируется — подделать IP нельзя.
