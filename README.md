# ToiШақыру — каталог электронных приглашений

React + Vite. Каталог из 180 шаблонов (`src/real_templates.js`) и предпросмотр
демоверсий, сохранённых в `public/demos/<id>/index.html`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
npm run lint
```

## Как устроен предпросмотр

Демо — это сохранённые страницы Next.js с сайта shaqyru24.kz. Само приглашение
лежит в `__NEXT_DATA__` и отрисовывается при гидратации, поэтому страница может
быть целой на диске и при этом показывать белый экран.

Отсюда два следствия, о которых легко забыть:

1. **Демо не автономны.** Рантайм Next.js, шрифты и звук грузятся с
   `shaqyru24.kz` и `tyrasoft.kz` по корневым путям `/_next`, `/fonts`,
   `/sounds`, `/uploads`. В `vite.config.js` для этого есть прокси — он
   подключён и к `dev`, и к `preview`.

   **Продакшену нужны те же правила.** На обычном статическом хостинге
   (GitHub Pages, S3 без правил) демо сломаются: ленивые чанки и шрифты
   отдадут 404. Нужен реверс-прокси на те же четыре пути — либо все ассеты
   надо вендорить к себе.

   Для Render это описано в [`render.yaml`](render.yaml): команда сборки,
   `staticPublishPath: ./dist` и четыре rewrite-правила. Без команды сборки
   Render просто ставит зависимости и отдаёт пустоту.

2. **Ссылки на ассеты привязаны к конкретному деплою вендора.** В URL зашиты
   хеши сборки. Когда shaqyru24.kz передеплоится, старые чанки исчезают и демо
   гидратируется в пустоту — молча. Так уже случилось с 8 шаблонами
   (347, 348, 358, 365, 366, 369, 379, 380); их перевели на живую сборку
   через `tools/repoint_demos.mjs`.

   Регулярно прогоняйте `node tools/audit_builds.mjs --probe`.

## Инструменты

Все скрипты запускаются из корня проекта.

| Скрипт | Что делает |
|---|---|
| `tools/audit_demos.mjs` | Проверяет payload каждого демо: есть ли блоки, не пустая ли страница |
| `tools/audit_builds.mjs --probe` | Группирует демо по сборкам вендора и проверяет, живы ли их ассеты |
| `tools/repoint_demos.mjs --ref <id> <id>...` | Переводит демо с мёртвой сборки на живую |
| `tools/strip_trackers.mjs` | Вырезает GTM, Google Ads, TikTok Pixel из сохранённых страниц |
| `tools/clean_demo_head.mjs` | Убирает canonical/hreflang/фавиконки/манифест вендора из `<head>` |
| `tools/sync_demos.mjs` | Ставит заглушки для отсутствующих демо и проставляет `demoAvailable` в каталоге |
| `tools/shoot_thumbnails.mjs <id>...` | Переснимает превью каталога со страницы демо (нужен запущенный `npm run dev`) |

Корневые `scrape_*.js`, `test_*.js`, `fetch_all_api.js` и т. п. — черновики,
которыми собирали данные. В сборку они не попадают.

## Что осталось нерешённым

- Пока демо грузят JS вендора, вместе с ним работает **Яндекс.Метрика**
  (счётчик 100775769) — она внутри их бандла, из наших файлов её не убрать.
  Лечится только вендорингом ассетов или собственным рендерером.
- Шесть шаблонов (57, 59, 100, 168, 210, 227) скачаны не полностью; для них
  показывается заглушка, кнопка «Демо көру» отключена.
- Весь контент демо принадлежит shaqyru24.kz. Публиковать в таком виде нельзя.
